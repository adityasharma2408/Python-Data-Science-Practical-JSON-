# Python Data Science Practicals

## Overview

This repository contains Python practicals covering JSON handling and data analysis using Pandas.

## Topics Covered

* Loading JSON data into Python objects
* Understanding Python dictionaries and lists
* Accessing JSON values
* Converting Python objects back to JSON
* Creating Pandas DataFrames
* Adding calculated columns
* Calculating grand totals
* Finding maximum values using Pandas

## Technologies Used

* Python
* JSON
* Pandas
* Google Colab

## How to Run

1. Download the `.ipynb` notebook.
2. Open [Google Colab](https://colab.research.google.com/).
3. Upload the notebook.
4. Run the cells sequentially.

## Learning Objective

To understand JSON data handling and basic data manipulation using Pandas.
